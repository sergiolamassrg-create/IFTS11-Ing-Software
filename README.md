# Quiz TP N.º 2 - Grupo 6

Cuestionario interactivo de repaso para Ingeniería de Software.

## Temas

- Modelo en V
- Programación Extrema (XP)
- Jira + Confluence

Incluye 30 preguntas, corrección inmediata, progreso, puntaje y un tablero final con fortalezas y temas para reforzar.

## Uso local

Abrir `index.html` en un navegador moderno. No requiere instalación, compilación ni dependencias externas.

## Publicación

El proyecto es un sitio estático y puede publicarse directamente con GitHub Pages, GitLab Pages, Netlify o servicios equivalentes. El archivo de entrada es `index.html`.
